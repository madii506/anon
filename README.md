# anon

The privacy layer for the city. A trading terminal on Solana (tokenized stocks, Jupiter perps, the pump.fun trenches, city coins) where every trade can be signed by a fresh wallet made in your browser and funded through a private route (NEAR Intents 1Click), so your main wallet never touches the trade.

- `/` home: the night city in 3D, a live wallet trace, live route quotes, live markets.
- `/app` the terminal. Key 0 opens the safehouse: make, fund, cash out, export and burn fresh wallets.
- `api/m.js` one Vercel function: prices, quotes, swaps, perps, trenches, the city, routes and traces. No keys and no custody.
