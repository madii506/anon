Overview

anon lets you launch pump.fun coins and trade any Solana token from keys that live in your browser. There is no account, no wallet to connect and no key import. The server builds transactions for a public address; your browser signs them; Solana receives them.

  • Launch: a pump.fun coin from a browser key, with your image, name, ticker and links.
  • Trade: any token Jupiter can route, pump.fun coins included.
  • Keys: make, fund, export, send and burn keys.
  • Routes: fund a key or cash out through NEAR Intents.

Keys

A key is an ed25519 keypair made with your browser's WebCrypto (or the Solana library where WebCrypto lacks ed25519). It is stored in this browser's localStorage under anon:keys. The secret never leaves the page.

Export and restore

Export saves a JSON file with the secret as base58 and as the 64-byte array solana-keygen uses, so it opens in other wallets. Restore reads that file, a byte array, or a base58 secret.

Burn

Burn deletes the key from this browser. Funds on its address stay on-chain; without an export they are out of reach for good.

Funding a key

Send SOL to the key's address from anywhere. An exchange withdrawal is the cleanest: your main wallet never appears in the key's history. To fund from USDC or ZEC, or to make the first funder a route's deposit wallet, use Routes.

Launching

  1. The page makes a mint keypair for the new coin.
  2. The server uploads your image and metadata to pump.fun's IPFS endpoint.
  3. PumpPortal's local transaction API builds the create transaction for your key, with your optional first buy.
  4. Your browser signs with your key and the mint key and sends it to Solana.

Creation needs a little SOL for rent and fees (under 0.02 SOL) plus the first buy. The coin's creator on-chain is your browser key.

Trading

Quotes and swap transactions come from Jupiter's API. Buys spend SOL; sells swap back into SOL. Slippage is yours to set. The swap is signed by the active key in this page and sent through the server's RPC relay.

Routes

Routes use NEAR Intents 1Click without an API key. You get a quote, then a one-time deposit address. Send the exact amount, and the route pays out to the address you chose. Supported: SOL, USDC (Solana) and ZEC, in both directions.

Cashing out from a key sends the SOL from the key to the deposit address automatically after you confirm.

Security model

  • Keys exist only in this browser. Anyone with access to this browser profile can use them: lock your device.
  • The server never receives a secret. It sees public addresses, the actions you ask for and signed transactions.
  • Every transaction is built by Jupiter or PumpPortal and checked by Solana. Review amounts before you sign.
  • The site loads no third-party scripts, sets no cookies and runs no analytics.

What the server does

One function, /api/m, with these actions: quote, swap, send, status, wallet, token, trench, launch, route, rquote, rstatus, rsubmit, bh, trace, prices. None of them takes a private key.

Limits

Everything on Solana is public. Fresh keys break the link to you; they don't hide what the key does. Funding from your main wallet, matching timing and matching amounts can all re-link a key. pump.fun's upload endpoint is outside our control.
